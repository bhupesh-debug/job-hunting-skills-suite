# Interview Prep — 80/20 Question Card Framework

Select the ~20% of questions that drive ~80% of interview outcomes for the specific
role/category mix implied by the JD. Don't pad with low-value filler.

## Priority system
- `##########` Almost Always Asked (95-100%) — **Must Master** — Dark Green
- `#########` / `########` Very High–High (70-94%) — **High ROI** — Green
- `#######` / `######` Common–Moderate (40-69%) — **Recommended** — Yellow
- `#####` / `####` Occasional–Rare (<40%) — **Optional/Low Priority** — Orange/Dark Red

(In a .docx, render color via a shaded heading bar or colored table cell per question,
since text color-coding alone is easy to miss when printed in grayscale — always pair
color with the text label like "Must Master.")

## Per-question card contents
1. Question
2. Priority hashtags + label (Must Master / High ROI / Recommended / Optional)
3. Why interviewers ask it + what competency it evaluates
4. Answer framework to use (STAR / CAR / SOAR / PREP)
5. Model answer — built from the *candidate's real resume facts only*
6. One-line "weak answer" contrast (what NOT to do)
7. 1-2 likely follow-ups

## Condensed-mode selection (≈15 questions)
Pick a spread across: 2-3 "Tell me about yourself / walkthrough" type, 4-5 role/technical
questions specific to the JD's top hard requirements, 3-4 behavioral/STAR questions
matched to competencies the JD stresses (e.g., stakeholder communication, attention to
detail, deadline management), 2 "why this company/role," 1-2 closing questions
(weaknesses, questions for the interviewer).
