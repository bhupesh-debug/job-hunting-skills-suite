# Resume & Cover Letter Rules

## Resume structure (1 page unless candidate has 15+ years and explicitly wants 2)
1. Name, target-title subtitle (e.g., "Senior Tax Associate — ASC 740 & Global Provision"),
   location, phone, email, LinkedIn.
2. Professional Summary — 3-4 lines, JD-aligned, quantified.
3. Core Competencies — single line or two, comma/pipe separated, real skills only,
   ordered by JD relevance.
4. Professional Experience — reverse chronological, 3-5 bullets per role, each bullet:
   action verb + what + how (tool/method) + quantified result. Reorder/re-emphasize
   existing bullets toward JD priorities; do not invent new ones.
5. Education, Certifications (only real/actual ones from the source resume).
6. Optional: Technical Skills, Simulations/Projects if present in source material.

## ATS keyword integration — visible only
Weave JD terminology into the summary, competencies line, and bullets *only where it's
truthfully supported by the candidate's real experience*. Do NOT add a hidden/invisible
keyword block (white text, near-white footer text, 1pt font, etc.) — this is a cloaking
technique that many ATS platforms flag and that damages candidate credibility if
discovered by a human reviewer. Prioritize genuine, readable keyword placement instead.

## Cover letter structure (one page)
- Opening: role + company + one specific hook tied to the company's actual work
  (from the JD or public info), not generic flattery.
- Body (2 paragraphs): 2-3 concrete achievements mapped to the JD's top requirements,
  in the candidate's own voice.
- Close: enthusiasm + call to action, no cliché "I look forward to hearing from you"
  as the only line — add one sentence of substance.

## Humanization checklist (apply to both docs before finalizing)
- Vary sentence length; avoid 3+ consecutive bullets with identical structure.
- Cut generic buzzwords ("results-driven," "dynamic self-starter," "team player") unless
  immediately backed by a specific example.
- No repeated transition phrases ("Additionally," "Furthermore," "Moreover" stacked).
- Every number must trace back to something in the source resume — never round up or
  invent a metric to sound more impressive.
